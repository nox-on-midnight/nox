Everything about Nox is a Midnight lesson

He's cute on purpose. Each part of him stands for one idea worth explaining to a friend.

  • The mask

    On most blockchains, every balance and transfer is visible to anyone, forever. Midnight is built so that sensitive data can stay private.

    Midnight idea: privacy by default

  • The wings

    Folded, nothing shows. Open, everything shows. Nox can open just one. Midnight apps can reveal a single fact to a single party, like an auditor, and keep the rest private.

    Midnight idea: selective disclosure

  • The orb

    Nox can prove the orb is real without letting you look inside. That's a zero-knowledge proof: you check that a statement is true without seeing the data behind it.

    Midnight idea: zero-knowledge proofs

  • The dust

    Moth wings are covered in tiny dust-like scales. On Midnight, holding NIGHT generates DUST, the resource that pays for transactions. It recharges over time, like a battery.

    Midnight idea: NIGHT and DUST

The roadmap (there isn't one)

We'll be honest with you: NightBringer has no roadmap. No app, no metaverse, no five-year plan. Its purpose is simply to exist, so that someone asks "what's that moth?" and walks away knowing what Midnight is.

Every project needs a roadmap section, though, so here's ours. In moon phases, out of respect for Midnight's own.

  1. New moon: exist Nearly there

    Nox exists. This website exists. The token joins them at launch, and with that, the hardest part of the plan is done.

  2. Waxing crescent: keep existing Ongoing

    Mostly involves not doing anything silly. Nox is very good at this. He's a moth.

  3. First quarter: get noticed Whenever

    Someone sees Nox, asks about him, and reads Midnight 101. That's the whole flywheel. It has one wheel.

  4. Full moon: exist, but shinier Eventually

    Same as before, with more light on it. The moon doesn't do anything either, and people have admired it for a very long time.

No dates, no deliverables, no promises. Looking for a real roadmap? Midnight has a good one.

Stay safe

Memecoins attract copycats. A few habits protect you from almost all of them.

Never

  • Share your seed phrase. Nobody legitimate will ever ask for it.
  • Trust a DM offering help, airdrops or early access. Announcements only come from the channels listed on this site.
  • Connect your wallet to a site you reached through a link in a DM.

Always

  • Compare the policy ID with the one on this site before you swap.
  • Check you're on this site or a link listed in the GitHub README.
  • Report impersonators in a GitHub issue so others get warned.
