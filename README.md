## Meet Nox

Nox, the masked night moth, is cute on purpose. Every part of him explains a Midnight idea:

| Nox | Midnight idea |
| --- | --- |
| The mask | **Privacy by default.** On most blockchains every balance and transfer is public forever. Midnight lets sensitive data stay private. |
| Folding wings | **Selective disclosure.** Reveal a single fact to a single party, like an auditor, and keep the rest private. |
| The golden orb | **Zero-knowledge proofs.** Prove a statement is true without showing the data behind it. |
| The dust | **NIGHT and DUST.** Holding NIGHT generates DUST, the shielded resource that pays for transactions. |
| Crescent moons | Midnight's roadmap phases are named after moon phases. |

Want the full picture in five minutes? Read [Midnight 101](https://nox-on-midnight.github.io/nox/midnight.html).

## Stay safe

**Never**
- share your seed phrase or private keys. Nobody legitimate will ever ask for them.
- trust a DM offering help, airdrops or early access. NightBringer contributors never DM first.
- connect your wallet to a site you reached through a link in a DM.

**Always**
- compare the policy ID with the one above before you swap.
- make sure you're on the [official website](https://nox-on-midnight.github.io/nox/index.html) or a channel listed below.
- report impersonators in a [GitHub issue](https://github.com/nox-on-midnight/nox/issues) so others get warned. More in [SECURITY.md](SECURITY.md).
